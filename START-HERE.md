# Publish your updated portfolio

This package includes the complete website, your updated portrait, all 128 slide images, and editable website source. The technology examples use the fictional company **Asterra**, an original logo, and generic capability names. The renamed **The Human Story Behind AI** presentation includes 21 slides.

## Update your existing repository with GitHub Desktop

1. Extract **Meghan-Fasano-Portfolio-Asterra.zip**. Open the `meghan-fasano-portfolio` folder inside it.
2. In GitHub Desktop, select your **Peerless_Portfolio_Meghan** repository. Choose **Repository → Show in Explorer**.
3. Replace the existing `app`, `public`, `site`, and `scripts` folders with the matching folders from the download. Replace each folder as a whole so removed older assets do not remain online. Keep the repository's `.git` folder.
4. Copy the remaining supplied files and folders into the repository folder, accepting file replacements. Include the `.github` folder.
5. In GitHub Desktop, review Changes, enter **Update portfolio with Asterra examples**, choose **Commit to main**, then **Push origin**.
6. On GitHub, open **Settings → Pages** and make sure **Source** is **GitHub Actions**.
7. Open **Actions → Publish portfolio**. The push normally starts publishing automatically. If necessary, choose **Run workflow → main → Run workflow**.

After the workflow succeeds, open the website address displayed in **Settings → Pages**. Refresh with **Ctrl + F5** if you still see an older image.

## Start a new repository instead

In GitHub Desktop, choose **File → Add local repository**, select the extracted `meghan-fasano-portfolio` folder, and use **create a repository here** if prompted. Publish the repository, then select **GitHub Actions** in **Settings → Pages** and run **Publish portfolio**.

## Important details

- Upload the extracted contents, not the ZIP itself.
- Keep the full package together. `site` contains the prepared pages, and `public` contains the images and other assets.
- Selecting **Deploy from a branch** can display the README instead of the portfolio. Use **GitHub Actions**.
- This package is ready to publish. Creating it does not change your live GitHub website.
- Your contact address remains **meghan@choosepeerless.com**.
- Asterra is a fictional sample company. Employment history uses neutral descriptions of the actual organization rather than attributing your career to Asterra.
